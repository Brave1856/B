# Brave Proxy

A dark, futuristic browser-style start page built with plain HTML/CSS/JavaScript.

## Run it
Open `index.html` in a browser.

## Deploy it
Upload the folder to a GitHub repository and import that repository into Vercel.
No build command is needed for this plain static version.

## Current features
- Brave home screen
- Search / URL field
- YouTube + Roblox shortcuts in one row
- AI panel (demo UI)
- Games panel
- Settings panel
- Responsive layout
- Black/silver wave background

## Important
The search field opens normal websites/searches. It is not a network-control bypass or school-filter circumvention system.

To make the AI real, add a backend endpoint and have `app.js` send chat messages to that endpoint. Keep the API key on the server, never in frontend JavaScript.
